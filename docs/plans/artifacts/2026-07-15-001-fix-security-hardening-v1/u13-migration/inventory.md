# U13 v0.5.1-to-1.0 Migration Inventory

Status: final U13 classification inventory after the U12 API freeze.

This artifact inventories the cumulative public changes that the English and
Korean 1.0 migration guides must cover. It is intentionally plan-adjacent and
does not modify the authoritative plan or the finding ledger.

## Scope and counting rules

- The planned pre-security range is `v0.5.1..150e579`, which contains exactly
  23 commits. The current `prepare-v1` branch contains one additional committed
  U1/U2 change (`8b1653f`), so `v0.5.1..prepare-v1` currently reports 24.
- The 23-row commit matrix below covers the cumulative pre-security changes.
  Security commit `8b1653f` is represented through the 77-row finding matrix
  rather than counted as a twenty-fourth prior change.
- The finding matrix contains exactly 77 reportable findings: 1 High,
  36 Medium, and 40 Low. Ignored `SK-DS-075` is deliberately absent.
- U12 public signatures, defaults, structured errors, and cross-surface replay
  are frozen. The idle clean-environment performance comparison is complete.
- Guide destinations are proposed stable anchors for both
  `docs/guide/migration-v1.md` and `docs/ko/guide/migration-v1.md`.
