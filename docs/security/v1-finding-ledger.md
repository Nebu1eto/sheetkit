# SheetKit 1.0 Security Finding Ledger

This ledger is the U1 baseline and U12 traceability record for the reportable
findings in Codex Security deep scan
`7e92b533-9ea8-4411-b4a9-252f9fb57dc2`, run against revision
`150e57939ac816a9bfa86daa856b432a135e3ca9`. It contains exactly 77 unique
reportable findings: 1 High, 36 Medium, and 40 Low. `SK-DS-075` is intentionally
excluded because the scan classified it as ignored.

The rows are ordered by severity (High, Medium, Low) and then numeric finding
ID. Row evidence records an observed owning-unit result; a historical test
count is not a claim that the current full repository is green. U12 aggregate
replay evidence is listed after the table. U13 classifies every migration
impact against the frozen API and links the required action to the final guide.
The final clean-environment performance evidence is recorded in the U14
performance receipt.
